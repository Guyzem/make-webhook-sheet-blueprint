# Make blueprint: Add webhook data to a Google Sheet

Imported from the Make template "Add webhook data to a Google Sheet" (template 5893).

## Import
1. In Make, create a new scenario and choose **Import Blueprint**.
2. Select dd-webhook-data-to-google-sheet.blueprint.json.
3. Create a new webhook in the first module.
4. In the Google Sheets module, choose your Google connection and your spreadsheet.
5. Send a test request to the webhook, then run once.
